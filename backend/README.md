# MONEY-MATE Backend

MONEY-MATE is a demo FinTech backend designed to provide secure payment processing, fraud detection, wallet management, offline transaction verification, financial insights, mandates, security monitoring, and an AI financial assistant.

## Technology Stack

- Python 3.11+
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- JWT Authentication
- bcrypt
- Alembic
- Uvicorn
- pytest
